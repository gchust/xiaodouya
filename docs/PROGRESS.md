# 功能进展

每个功能一行。**这里写的必须是已经发生的事实**：没跑过就写未验证，不写“应该没问题”。

## 怎么更新

- 开始做：把状态改成“开发中”，在“负责”里写分支名。别的 Agent 看到就不要重复做同一项。
- 做完或改了行为：在同一个 PR 里更新这一行，写明验证依据。
- 改动破坏了已验证的功能：把对应的验证退回 ⬜，放行改回“否”。
- 新功能：追加新行，用新编号。编号不复用，不改旧行的编号，这样并行开发时冲突最少。
- 只改自己负责的行，不顺手重排表格。
