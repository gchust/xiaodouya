# 小豆芽设计规范

来源：Claude Design 原型「宝宝成长记录 原型」风格 1a。这里是实现的唯一视觉依据。

气质：像一本温暖的纸质成长册，不像后台工具。米色纸张、衬线标题、等宽数字、赤陶色点缀。没有图标堆砌，用小圆点和文字说话。

| `card`        | `#fffdf9`             | 卡片、底部弹层       |
| `sand`        | `#efe6d9`             | 提示卡、头像底       |
| `line`        | `#ebe2d6`             | 卡片和导航边框       |

记录类型颜色：喂奶 `#c0714f`，尿布 `#c9a24a`，睡眠 `#7d8fb8`，体温 `#b8645e`，吃药 `#8a7a9e`，洗澡 `#6f9aa0`，身高体重和疫苗 `#6f9a6a`。尿尿 `#d9c06a`，便便 `#a07a3a`。

### 字体

- 标题和手写内容：Noto Serif SC（500、700）。这种字体给 App 成长册的感觉，不能换成系统字体。
- 数字和时间：DM Mono（400、500）。
- 其他：系统无衬线（Android 为 Noto Sans CJK）。

字号：页面标题 26/700 衬线；分区标题 15/700 衬线；时间线标题 18/700 衬线；计时器 32/500 等宽；弹层大数字 52/500 等宽；正文 13–14；辅助 11–12。

### 形状和动效

- 圆角：卡片 14，提示卡 12，弹层顶部 24，主按钮 16（高 54），胶囊 999。
- 页面左右边距 22。
- 弹层和页面切换 340ms，`cubic-bezier(.2,.8,.2,1)`。按压缩放到 0.95。
- 遮罩 `rgba(43,38,34,.38)`。Toast 为深色胶囊，显示 3.6 秒，可撤销。

## 2. 导航

底部四个文字标签：**今天、回忆、资料、家人**。没有图标，激活态是上方 18×3 的赤陶色短条加粗体。二级页从右侧滑入，顶部是 `‹ 上一页`。

## 3. 今天

从上到下：

1. 日期（`10月31日 · 星期六`）、标题 `小豆芽的第 N 天`（用宝宝名字）、月龄（`1 个月零 1 天`），右上角 44 圆形头像（点击从相册换照片，没有照片时显示条纹）。
2. 喂奶计时卡：`距上次喂奶`，`H:MM` 大数字，右上提示（`约 13分钟后该喂了` / `已到平时的喂奶间隔`，距离小于 30 分钟变赤陶色），下方上次喂奶摘要。点击打开喂奶弹层。
3. 四个快捷按钮：喂奶（赤陶实心）、尿布、睡眠、更多。睡眠中按钮变蓝色并显示「醒了」。
4. `根据记录` 提示卡（见第 8 节）。
5. `过去 24 小时` + 摘要（`喂奶 4 次 · 330ml 尿布 4 睡 1.1h`），时间线最多 8 条，只放这 24 小时里的（这一栏只显示钟点）：等宽时间 + 彩色圆点 + 标题 + 备注和记录人。点击显示完整时间，可以修改或删除。下面一行小字链接：`全部记录 ›`（左）、`＋ 补记`（右）。补记放在这里，不和快捷按钮抢位置。
6. `疫苗提醒` 卡，点击进入接种弹层。有常规剂次到期时才显示。

**全部记录页：** 从右侧滑入，`‹ 今天` + `全部记录`，右上 `＋ 补记`，类型胶囊筛选（全部 / 喂奶 / 尿布…，可换行），按天分组，新的在前。身高体重不进今天的时间线，要从这里改。

### 记录弹层（都支持时间胶囊：刚刚 / 15 分钟前 / 30 分钟前 / 1 小时前 / 更早）

默认“刚刚”，不增加步骤。点 `更早` 才展开两个等宽按钮（日期、时刻，打开系统选择器）和 `今天 / 昨天 / 前天` 胶囊。修改和从 `＋ 补记` 进来时直接显示这一组。

时间规则（`packages/shared/src/domain/recordTime.ts`）：未来时间和“醒来早于睡着”用 `danger` 色提示并禁用保存；早于出生只用 `accent` 色提示一句，可以保存，因为出生时间本身可能填错，孕期的回忆也是合理的。

修改记录时，按钮写 `保存`，保留原来的记录人，Toast `已保存 · …` 可撤销。备注输入框只在修改时出现，新记录要少点几下。

- **喂奶**：± 按钮 + 52 号数字（步长 10），快捷 60/80/90/100/120，备注，`记录`。默认值取上一次奶量。
- **换尿布**：尿尿 / 便便 / 都有三个大按钮，点一下就记好。
- **更多**：体温、吃药、洗澡、身高体重、疫苗；辅食 6 个月后开放（未到月龄时半透明）。
- **体温**：± 步长 0.1。颜色和提示随温度变化（见第 8 节）。
- **吃药**：快捷（维生素D / 益生菌 / 退烧药）+ 药名 + 剂量。
- **洗澡**：一句注意事项 + `记录洗澡`。
- **身高体重**：两行步进器（体重 0.1kg，身长 0.5cm）。
- **睡眠**：平时在今天页点一下开始、再点一下结束。补记和修改时有 `睡着`、`醒来` 两组时间；还没结束的睡眠有 `还在睡` 开关。
- **疫苗**：接种日期（默认今天，有 `今天 / 昨天 / 前天` 胶囊，可以补记以前的，不能选未来）；待接种列表单选，最后一项 `其他疫苗` 自己填名字；绿色 `已接种`。已记的点开后能改日期和备注，自定义疫苗还能改名字，是哪一剂不能改。从疫苗本的某一行或疫苗提醒进来时，顶部多一行：这一剂的时间（表上的月龄或 `计划 日期`），右边两个小字链接 `改时间`、`隐藏这一剂`；自己加的疫苗是 `修改`、`移除`。

保存后 Toast：`已记录 · 喂奶 90ml · 已同步给妈妈` + `撤销`。其他家人的记录到达时，顶部滑入深色横幅：一条时写“妈妈 记录了 喂奶 75ml”，多条时汇总成“妈妈 记了 3 条，最近是 喂奶 120ml”。不做远程推送，打开 App 时才会看到。

## 4. 回忆

标题加四个子标签：时间线 / 照片 / 里程碑 / 写给你。右下角悬浮深色胶囊 `＋ 记下这一刻`（在「写给你」下是 `＋ 写一封信`）。

- **时间线**：标题 + 等宽日期和天数 + `里程碑` 描边标签；200 高封面（视频有播放键，`共 N 项`）；录音卡（圆形播放键 + 波形 + 时长，播放时波形按进度变赤陶色）；衬线正文；`妈妈写`。
- **照片**：按回忆分组的 3 列方格，视频显示 `▶ 0:24`。点开全屏浏览。
- **里程碑**：已记录的实心圆 + 日期 + `查看`；未记录的空心圆 + 通常月龄 + `记录`。底部注明“月龄只是大致参考，每个宝宝节奏不同。”
- **写给你**：卡片式信件，衬线正文。

**记下这一刻弹层**：这一刻 / 写给宝宝的信 切换；虚线框的「照片 / 视频」（多选）和「录音」（录音中变赤陶实心并计时）；已选缩略图可删除；标题、正文（衬线）；时间胶囊（`现在` / `更早`）；`标为里程碑` 开关；深色 `保存`。保存后顶部显示上传进度卡片，可以关掉，状态变化时重新出现，不挡下面的点击。

**修改回忆和信：** 时间线和信的卡片上的 `⋯` 进入，只看的家人没有这个入口。标题是 `修改这一刻` / `修改这封信`，不能在两者之间切换。已有的文件和新选的放在一排，都能移除；移除是从记录里摘掉，Toast `已保存` 可撤销；没有别的记录用这个文件时，平台存储在宽限期（`MEDIA_TRASH_DAYS`，默认 30 天）后清理，规则见 ARCHITECTURE。早于出生的回忆显示 `出生前 N 天`。

## 5. 资料

分区：出生档案（可编辑，最后一行 `地区` 只有管理员能点）、证件夹（2 列卡片 + `＋ 添加`，建议项来自地区）、体重（柱状图，最新一根不透明，标题带单位）、疫苗本（状态点 + 接种时间，标题右边 `一次补记`、`＋ 其他疫苗`，表下面右对齐一行小字 `已隐藏 N 剂 ›`（有隐藏时才有），再下面是 `其他接种记录`，页脚是地区的说明）、这个月该知道的（知识卡，页脚免责声明）。

换地区在弹层里选好后，用一句话说明影响（记录不丢，放到其他接种记录，默认单位会变），再点 `确定换成…`。疫苗本的状态文字：`已接种 日期`、`可以预约了`、`未到时间`；看情况的剂次写 `看情况`，共同决定的写 `和医生商量`，都不用赤陶色，不提醒。其他地区没有疫苗表，只显示一句解释和自己记的内容。

**配置疫苗本：** 没有配置页，入口都在疫苗本上，常见操作两三步。配置是家庭的覆盖层，不改内置表；App 不判断时间是否合理。

- **隐藏：** 点一行 → `隐藏这一剂`，Toast 可撤销。已打过的不能隐藏。`已隐藏 N 剂 ›` 里每行一个 `恢复` 胶囊。
- **改时间：** 点一行 → `改时间` → `下周` / `下个月` / `选日期` 胶囊，`保存`。状态写 `计划 日期`（不写“可以预约了”，已经约好了），提前两周变赤陶色。已改过的多一个 `恢复表上的时间`。
- **加一个疫苗：** `＋ 其他疫苗` → `还没打，加进计划` → 名称，时间可选（`下周` / `下个月` / `选日期` / `按月龄`），`加进计划`。默认仍是 `已经打了`，记一剂打过的不多一步。副标题写 `自己加的`，没填时间的状态是 `时间待定`，排在最后。
- **一次补记：** `一次补记` → 上面选日期，下面勾选（圆形勾选框，绿色），勾上的行右边显示日期，点它单独改，改过的变赤陶色；绿色 `记下 N 剂`，Toast `已记录 N 剂` 可一次撤销。列出所有没记的，包括看情况的剂次。

**证件详情页**：名称和副标题（都能改）；证件号默认打码（`T26•••••A`），点一下显示；签发日期；文件 2 列 3:4 预览，每个文件下面有 `移除`，可撤销；`拍照 / 扫描` + `上传文件`；页脚说明“存放在私有目录，不会出现在回忆里。”证件夹可用指纹解锁。

## 6. 家人

成员列表（圆形首字头像、称呼、角色、状态）+ `＋ 邀请家人`；提醒（喂奶提醒，只看回忆的家人没有这一组）；设置（存储、单位、导出成长册、退出登录）。

**单位弹层**：奶量、体温、体重、身长各一行，两个胶囊（ml/oz、℃/°F、kg/lb、cm/in），底部 `恢复…的默认单位`。单位属于个人，默认跟随家庭的地区，只改变显示。

| 单位 | 步长 | 快捷值 |
| ---- | ---- | ------ |
| ml / oz | 10 / 0.5 | 60、80、90、100、120 / 2、3、4、5、6 |
| ℃ / °F | 0.1 / 0.2 | — |
| kg / lb | 0.1 / 0.2 | — |
| cm / in | 0.5 / 0.5 | — |

不在网格上的值（家人记的 130ml 显示成 4.4oz）按一下先对齐到相邻的格子。成长册的纸张来自地区（美国用 Letter，其他用 A4），内容里没有数量。

**存储页（用量）**（管理员和一起记录的家人）：托管存储时看到的页面。已用和总量，分类占比条（比例按总量算，看得出还剩多少），到 80% 和 100% 时一句提醒，一段说明，选项开关。没有任何 S3 的内容。

**存储页（自定义）**（仅管理员，且服务器允许自定义存储）：用量卡（分类占比条），服务商切换（Cloudflare R2 / AWS S3 / 其他 S3 兼容），配置表单（等宽字体），`测试连接`（真实读写校验），选项开关，`保存`。

## 7. 相对原型的有意改动

| 原型                         | 现在                                                     | 原因                                       |
| ---------------------------- | -------------------------------------------------------- | ------------------------------------------ |
| Secret 看起来存在手机        | 只写入服务端，App 永远读不回来                           | 否则每台手机都能读全部证件                 |
| 自定义域名 + 10 分钟签名链接 | 私有文件走存储 API 域名，域名字段只用于公开读的 CDN 场景 | R2 预签名链接不支持自定义域名              |
| “新加坡节点 11ms”            | 显示真实的连接测试结果和耗时                             | R2 只能选 APAC，不保证在新加坡             |
| 乙肝第 2 剂在 1 个月         | 按 NCIS 改为随 2 个月六合一                              | 原型过时                                   |
| “6–8 次都正常；吃够了”       | 按真实数据给提示，偏少时建议留意                         | 不能在数据不足时安慰                       |
| 称呼“他”                     | “宝宝”或名字                                             | 不假定性别                                 |
| “证件本地加密”开关           | 改为证件夹指纹解锁                                       | 端到端加密的家庭密钥分发容易造成永久丢数据 |
| “流量下传压缩版”             | 视频等 Wi-Fi 再传                                        | 不改变原文件，更可靠                       |
| “瓶喂”                       | “喂奶”                                                   | 不是每次喂奶都用奶瓶                       |
| “本周可接种”                 | “可以预约了”                                             | 提前两周提示，这样说更准确                 |
| “私有访问”“缩略图”开关       | 不提供开关，两项始终开启                                 | 都是安全的默认值，不需要用户选择           |
| 记录不足时默认按 3 小时估算  | 至少 3 次喂奶后才估算下次时间                            | 默认的猜测不能用来驱动提醒                 |

## 8. 健康提示规则

规则和来源在 `packages/shared/src/health/`。体温：≥38℃ 红色“3 个月以下的宝宝 38℃ 及以上，请尽快就医”；37.5–38℃ 赤陶色“有点偏高，松松衣服，30 分钟后再量一次”；否则“正常范围”。判断永远用摄氏度，文字里的阈值按用户的单位显示（38℃ 写成 100.4°F）。
