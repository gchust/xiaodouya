# 小豆芽设计规范

来源：Claude Design 原型「宝宝成长记录 原型」风格 1a。这里是实现的唯一视觉依据。

气质：像一本温暖的纸质成长册，不像后台工具。米色纸张、衬线标题、等宽数字、赤陶色点缀。没有图标堆砌，用小圆点和文字说话。

## 1. 设计令牌（实现见 `apps/mobile/src/themes/palettes.ts`）

下表是默认主题「暖纸」的浅色版，也就是原型的配色。其他主题和深色版见“主题配色”一节。

| 令牌          | 值                    | 用途                 |
| ------------- | --------------------- | -------------------- |
| `paper`       | `#f6f1ea`             | 页面背景、次级按钮   |
| `card`        | `#fffdf9`             | 卡片、底部弹层       |
| `sand`        | `#efe6d9`             | 提示卡、头像底       |
| `line`        | `#ebe2d6`             | 卡片和导航边框       |
| `rule`        | `#efe7dc` / `#f1eadf` | 列表分隔线           |
| `ink`         | `#2b2622`             | 主文字、深色按钮     |
| `inkSoft`     | `#4a423c`             | 正文次级             |
| `muted`       | `#6f655d`             | 辅助文字（F-142 前是 `#7a6f66`，在 `sand` 上只有 3.96:1） |
| `accent`      | `#c0714f`             | 主操作、激活态       |
| `accentLight` | `#e9a585`             | 深底上的强调（撤销） |
| `off`         | `#d8cfc3`             | 开关关闭、波形未播放 |
| `green`       | `#6f9a6a`             | 成功、疫苗、在线     |
| `danger`      | `#c4483f`             | 发烧、失败、删除确认（F-142 前是 `#b8645e`） |
| `stripeA/B`   | `#e5dccf` / `#ede5d9` | 图片占位条纹（135°） |

**文字和按钮另有令牌（F-142）。** 上面的 `accent`、`green`、`danger`、`sleep` 是色块、圆点、进度条、导航短条和开关的颜色。原型直接拿它们写小字和做白字按钮，对比度达不到 WCAG AA（`accent` 写在 `paper` 上 3.27:1，白字压在 `accent` 上 3.67:1）。所以：

- 写成文字时用 `accentText` `#94563c`、`dangerText` `#a8322c`、`greenText` `#4c6e48`、`sleepText` `#54638a`，提醒用 `warnText` `#94563c`。
- 有字压在上面的实心按钮用 `accentFill` `#a9603f` + `onAccent`，`dangerFill` `#a8322c`、`greenFill` `#567c52`、`sleepFill` `#5f709a`，字都是白色。
- 深色按钮、Toast、选中的胶囊仍然是 `ink` 底 + `paper` 字；深色模式下两者对调。

纸、卡片、墨、强调色的色块都和原型一样，只有字和白字按钮的底深了一档。表示发烧、失败、删除的红改得更红（`danger` `#b8645e` → `#c4483f`）：原来它和 37.5–38℃ 用的赤陶色色差只有 12，同一个体温弹层里加减 0.1 就换颜色，看起来却差不多。

记录类型颜色：喂奶 `#c0714f`，尿布 `#c9a24a`，睡眠 `#7d8fb8`，体温 `#b8645e`，吃药 `#8a7a9e`，洗澡 `#6f9aa0`，身高体重和疫苗 `#6f9a6a`。尿尿 `#d9c06a`，便便 `#a07a3a`。

### 字体

- 标题和手写内容：Noto Serif SC（500、700）。这种字体给 App 成长册的感觉，不能换成系统字体。
- 数字和时间：DM Mono（400、500）。
- 其他：系统无衬线（Android 为 Noto Sans CJK）。

英文也用这两种字体：子集字体含全部 ASCII 和 `… · ‹ ›`，英文不要在衬线标题里用弯引号，用直的 `'` 和 `"`。

字号：页面标题 26/700 衬线；分区标题 15/700 衬线；时间线标题 18/700 衬线；计时器 32/500 等宽；弹层大数字 52/500 等宽；正文 13–14；辅助 11–12。

### 形状和动效

- 圆角：卡片 14，提示卡 12，弹层顶部 24，主按钮 16（高 54），胶囊 999。
- 页面左右边距 22。
- 弹层和页面切换 340ms，`cubic-bezier(.2,.8,.2,1)`。按压缩放到 0.95。
- 遮罩 `rgba(43,38,34,.38)`。Toast 为深色胶囊，显示 3.6 秒，可撤销。

### 删除确认（issue #78）

**删除或移除已保存的数据都要二次确认：** 记录（含身高体重、接种记录）、回忆、信、证件和证件里的文件、奶粉、自己加的疫苗计划、把家人移出家庭。点了删除，当前弹层换成确认弹层（不在弹层里的，比如证件文件的 `移除`，直接打开）：

- 标题是一句问句，写清楚删的是什么：`删除这条喂奶记录？`、`删除卡介苗的接种记录？`、`删除回忆“第一次笑”？`、`移除扫描件.pdf？`、`把妈妈移出家庭？`。
- 下面一段 `muted` 说明：记录先写这条记录本身（`喂奶 90ml · 11月5日 09:30`），再说后果（全家都看不到了）和 `删完可以马上撤销。`；移出家庭没有撤销，就不提撤销，写清楚对方会怎样。
- 然后是 `danger` 色实心按钮（`删除` / `移除` / `移出家庭`），最下面是描边的 `取消`。取消放在最下面：弹层贴着底部，原来的删除按钮多在弹层最下面，连点两下时第二下落在 `取消` 上。点遮罩、右上角的 `取消` 也是取消，取消后弹层关掉，什么都不变。
- 确认后和原来一样：软删除、同步给家人，Toast `已删除…` 可撤销。
- 不用 `Alert`：系统对话框和弹层的样式不一致，Maestro 也要另外处理。

**不用确认的：** 还没保存的内容（`记下这一刻` 和反馈里刚选的照片、修改回忆时移除的文件：要点 `保存` 才生效，保存后的 Toast 可撤销）；隐藏内置疫苗剂次（只是开关，`已隐藏 N 剂` 里随时恢复）；撤销本身；记录流程（记录永远一下就好）。已经有自己的确认的不再加一层：退出登录、删除账号（输密码）、取消上传、取消邀请（弹层）、撤销分享链接（点两次）。

实现：`apps/mobile/src/ui/DeleteConfirm.tsx`，文字在 `packages/shared/src/domain/deleteConfirm.ts`。

## 2. 导航

底部四个文字标签：**今天、回忆、资料、家人**。没有图标，激活态是上方 18×3 的赤陶色短条加粗体。二级页从右侧滑入，顶部是 `‹ 上一页`。

## 3. 今天

从上到下：

1. 日期（`10月31日 · 星期六`）、标题 `小豆芽的第 N 天`（用宝宝名字）、月龄（`1 个月零 1 天`），右上角 44 圆形头像（没有照片时显示条纹，点击直接从相册选；有照片时点击全屏看原图，底部是 `换一张`、`旋转`、`裁剪`。旋转和裁剪先预览，点 `保存` 才上传。裁剪用正方形取景框，一根手指拖动、双击放大。只看回忆的家人没有这些按钮。头像这里不提供下载，下载在回忆里）。
2. 喂奶计时卡：`距上次喂奶`，`H:MM` 大数字，右上提示（`约 13分钟后该喂了` / `已到平时的喂奶间隔`，距离小于 30 分钟变赤陶色），下方上次喂奶摘要。点击打开喂奶弹层。
3. 四个快捷按钮：喂奶（赤陶实心）、尿布、睡眠、更多。睡眠中按钮变蓝色并显示「醒了」。
4. `根据记录` 提示卡（见第 8 节）。
   下面是可以关掉的提示卡（卡片底、细边、圆角 12，左边一句话，右边灰色 `以后再说` 和赤陶色的动作），放在按钮下面而不是上面：出现时不会把按钮挤走。有两种：打开通知；新版本已下载好（F-130，`新版本 0.6.0 已下载好` + `安装`，点了调起系统安装，没有“安装未知应用”的授权时打开更新弹层；`以后再说` 后同一个版本不再出现）。不用 Toast：Toast 只有一个位置，会顶掉 `已记录 · 撤销`。
5. `奶粉营养` 一行，只在今天有喂奶记录时显示：右边是 `目前已摄入蛋白质 42%` 或 `数据不足 · 有 3 次喂奶没算进去`，不说够不够。点击进入奶粉营养页。放在时间线上面，时间线一满 8 条，下面就要滚动才看得到。
6. `过去 24 小时` + 摘要（`喂奶 4 次 · 330ml 尿布 4 睡 1.1h`），时间线最多 8 条，只放这 24 小时里的（这一栏只显示钟点）：等宽时间 + 彩色圆点 + 标题 + 备注和记录人。点击显示完整时间，可以修改或删除（删除先确认，见第 1 节“删除确认”）。下面一行小字链接：`全部记录 ›`（左）、`＋ 补记`（右）。补记放在这里，不和快捷按钮抢位置。
7. `疫苗提醒` 卡，点击进入接种弹层。有常规剂次到期时才显示。

**全部记录页：** 从右侧滑入，`‹ 今天` + `全部记录`，右上 `＋ 补记`，类型胶囊筛选（全部 / 喂奶 / 尿布…，可换行），按天分组，新的在前。身高体重不进今天的时间线，要从这里改。

**搜索记录（F-144，issue #109）：** 标题下面一个胶囊形搜索框（`card` 底、`line` 细边、高 44，没有放大镜图标，占位 `搜药名、体温、备注、谁记的`），有字时右边灰色 `×` 清空。和类型胶囊同时生效：先按类型筛，再按字搜。搜的是列表上看到的标题（按当前语言和单位，比如 `体温 38.5℃`）、类型名（搜 `睡眠` 也能找到 `睡了 1小时`）、备注、记录人、药名和剂量、辅食、奶粉名，疫苗的中英文名都搜得到。不分大小写和全角半角，拉丁字母不分重音，空格分开的几个词都要命中。有字时胶囊下面一行 `muted` 的 `找到 N 条`；结果和平时一样按天分组，命中的字是 `accentText` 加粗（另一种语言的疫苗名命中时没有可标的字，只是显示出来）；点开和平时一样能改、能删。没有结果是空状态 `没有找到“…”` + `换个说法试试。`（选了类型时多一句 `或者把上面的类型换成“全部”`）。规则在 `packages/shared/src/domain/search.ts`。

### 记录弹层（都支持时间胶囊：刚刚 / 15 分钟前 / 30 分钟前 / 1 小时前 / 更早）

默认“刚刚”，不增加步骤。点 `更早` 才展开两个等宽按钮（日期、时刻，打开系统选择器）和 `今天 / 昨天 / 前天` 胶囊。修改和从 `＋ 补记` 进来时直接显示这一组。

时间规则（`packages/shared/src/domain/recordTime.ts`）：未来时间和“醒来早于睡着”用 `danger` 色提示并禁用保存；早于出生只用 `accent` 色提示一句，可以保存，因为出生时间本身可能填错，孕期的回忆也是合理的。

修改记录时，按钮写 `保存`，保留原来的记录人，Toast `已保存 · …` 可撤销。备注输入框只在修改时出现，新记录要少点几下。

- **喂奶**：± 按钮 + 52 号数字（步长 10），快捷 60/80/90/100/120，备注，一行收起的奶类型（`奶粉 · 名字`，点开才有奶粉 / 母乳 / 混合和奶粉列表），`记录`。默认值取上一次的奶量、奶类型和奶粉，不多一步。
- **换尿布**：尿尿 / 便便 / 都有三个大按钮，点一下就记好。
- **更多**：体温、吃药、洗澡、身高体重、疫苗；辅食 6 个月后开放（未到月龄时半透明）。
- **体温**：± 步长 0.1。颜色和提示随温度变化（见第 8 节）。
- **吃药**：快捷（维生素D / 益生菌 / 退烧药）+ 药名 + 剂量。
- **洗澡**：一句注意事项 + `记录洗澡`。
- **身高体重**：两行步进器（体重 0.1kg，身长 0.5cm）。
- **睡眠**：平时在今天页点一下开始、再点一下结束。补记和修改时有 `睡着`、`醒来` 两组时间；还没结束的睡眠有 `还在睡` 开关。
- **疫苗**：接种日期（默认今天，有 `今天 / 昨天 / 前天` 胶囊，可以补记以前的，不能选未来）；待接种列表单选，最后一项 `其他疫苗` 自己填名字；绿色 `已接种`。已记的点开后能改日期和备注，自定义疫苗还能改名字，是哪一剂不能改。从疫苗本的某一行或疫苗提醒进来时，顶部多一行：这一剂的时间（表上的月龄或 `计划 日期`），右边两个小字链接 `改时间`、`隐藏这一剂`；自己加的疫苗是 `修改`、`移除`。

保存后 Toast：`已记录 · 喂奶 90ml · 已同步给妈妈` + `撤销`。其他家人的记录到达时，顶部滑入深色横幅：一条时写“妈妈 记录了 喂奶 75ml”，多条时汇总成“妈妈 记了 3 条，最近是 喂奶 120ml”。不做远程推送，打开 App 时才会看到。

**奶粉营养页**：`‹ 今天`，标题，前后翻一周内的日子。数据不足时最上面是提示卡，逐条写原因。七种营养素一张列表卡：名称、状态（`目前已摄入 42%` 深色；`达到参考量` 绿色；`低于参考量` 赤陶色；`数据不足`、`不作比较` 灰色）、等宽的 `已算的量 / 参考量`、4 高的细进度条（超过 100% 也只画满）。下面是估算说明、`估算，不能替代医生建议`、参考量来源。最后是 `家里的奶粉` 列表和 `＋ 添加`。不用红色，不评价品牌。

**添加奶粉**：`手动填写` 或从预置里选，都进同一张表单，保存前能对照罐身看一遍。预置注明“这里只是列出来，不代表推荐”。表单：名称、每 100 ml 或每 100 g（后者要填冲调比例）、七个数字，能量可切 kcal / kJ，维生素 D 可切 µg / IU。

## 4. 回忆

标题加四个子标签：时间线 / 照片 / 里程碑 / 写给你。右下角悬浮深色胶囊 `＋ 记下这一刻`（在「写给你」下是 `＋ 写一封信`）。

- **时间线**：标题 + 等宽日期和天数 + `里程碑` 描边标签；200 高封面（视频有播放键，`共 N 项`）；录音卡（圆形播放键 + 波形 + 时长，播放时波形按进度变赤陶色）；衬线正文；`妈妈写`。
- **照片**：按回忆分组的 3 列方格，视频显示 `▶ 0:24`。点开全屏浏览。
- **全屏查看照片**：黑底，默认显示预览，先有缩略图。底部居中一个胶囊，半透明黑底白字 13 号：能点时有白色细边（`查看原图 8.4 MB`、加载失败时的 `原图没有加载出来，点这里再试一次`）；只说状态时没有边（`正在加载原图 35%` 带小转圈、`已显示原图 8.4 MB`、`原图还在上传`）。旧照片没有预览，直接显示原图。
- **封面**：一条回忆有两个以上照片或视频时，全屏查看的顶部在页码旁边有 `设为封面`（白色细边胶囊，12 号），已经是封面的那一张换成 `● 封面`（`accentLight` 小圆点，没有边，只说状态）。点了 Toast `已设为封面` 可撤销。时间线的 200 高封面用它，点封面从这一张打开。没设置过或封面被移除时用第一个。修改弹层里，已有文件中的封面左上角有赤陶色小标签 `封面`。只看回忆的家人没有这个入口。
- **里程碑**：已记录的实心圆 + 日期 + `查看`；未记录的空心圆 + 通常月龄 + `记录`。底部注明“月龄只是大致参考，每个宝宝节奏不同。”
- **写给你**：卡片式信件，衬线正文。

**记下这一刻弹层**：这一刻 / 写给宝宝的信 切换；虚线框的「照片 / 视频」（多选）和「录音」（录音中变赤陶实心并计时）；已选缩略图可删除；标题、正文（衬线）；时间胶囊（`现在` / `更早`）；`标为里程碑` 开关；深色 `保存`。保存后顶部显示上传进度卡片，可以关掉，状态变化时重新出现，不挡下面的点击。

**搜索回忆和信（F-144，issue #109）：** 标题 `回忆` 右边紧挨着 13 号强调色小字 `搜索`，四个子标签下都有，选几段分享时不显示。点了从右侧滑入搜索页：`‹ 回忆`、标题 `搜索回忆`、和全部记录一样的搜索框（打开就有焦点）。没输入时一句 `muted` 说明能搜什么。搜回忆和信的标题、正文，规则和搜记录一样。结果回忆和信放在一起，按天分组、新的在前，每条一行（行间 `rule` 分隔线）：回忆左边 48 圆角 10 的封面缩略图（没有照片是条纹），信没有；右边 11 号 `回忆 · 09:30` / `信 · 09:30`、衬线粗体标题、最多 3 行衬线正文。命中的字是 `accentText`，衬线里用粗体的字体文件。命中在正文后面时从上一句结尾开始截，前面加 `…`。点一行打开弹层：等宽的日期时间（回忆加 `第 N 天`）、衬线全文（同样高亮）、`妈妈写`、录音卡、深色 `看照片和视频`（有照片或视频时），能写的家人还有描边 `修改` 和灰色 `删除这条回忆` / `删除这封信`（先确认，Toast 可撤销）。只看回忆的家人也能搜，只是没有修改和删除。

**收藏回忆（F-143）：** 时间线卡片标题行右边、`⋯` 左边一个 `☆`，点一下收藏，变成赤陶色 `★`，Toast `已收藏` 可撤销；再点取消。`⋯` 弹层里多一个描边 `放进收藏夹`。收藏集中在资料页的“收藏”，见第 5 节。只看回忆的家人没有 ☆。

## 发送链接（F-139，issue #94）

三种分享（一天、时间线、回忆）建好链接后是同一块（`shareCreated.tsx`）：`链接已创建`、写明类型的一行、链接、还没传完的说明、一句提醒，下面是发送，最后是红色小字 `撤销这个链接`。

**Android：** 系统分享面板会列出手机上所有能收文字的 App，而且不能过滤，所以直接列出常用的聊天 App。

- 12 号 `muted` 小字 `发送到`，下面一排最多 5 格平分：按地区排好的常用 App（只显示这台手机装了的，最多 4 个），最后一格 `更多`。每格是 44 的图标（圆角 12）加 11 号 `inkSoft` 名字（一行，超出省略）。图标和名字都是系统给的（应用图标、`loadLabel`，跟着手机语言，比如中文手机上是 `微信`），不打包别人的商标图片；取不到图标时是 `sand` 底的衬线首字。`更多` 是 `paper` 底、`line` 细边的方块里一个 `···`，打开系统分享面板。
- 点一个 App 直接打开它，带上整段文字（和系统分享面板发的一样）。微信这类一个 App 有好几个入口的（`发送给朋友`、`添加到微信收藏`），系统只在这个 App 的入口里让人选。打不开时红字 `没能打开这个 App，可以点“更多”或复制链接。`
- 下面是描边按钮 `复制链接`（高 46），点了变成 `已复制`（不定时变回去，Android 13 起系统自己也会提示一下）。只复制链接，不带说明文字。
- 名单里的一个都没装：没有这一排，和 iOS 一样是一整行的 `发送给别人`（打开系统分享面板），下面照样有 `复制链接`。
- 建好链接时不自动打开系统分享面板，先让人看到这一排。

**各地区的名单**（`packages/shared` 的 `regions/shareTargets.ts`，按顺序）：中国大陆 微信、QQ、WhatsApp、Telegram；新加坡 WhatsApp、Telegram、微信、短信、LINE；美国 短信、WhatsApp、Messenger、Telegram、Signal；其他地区 WhatsApp、Messenger、Telegram、微信、LINE、Viber、KakaoTalk、Signal、QQ、短信。短信用手机设置的默认短信 App。

**iOS：** 查不了装了什么，也不能指定发给谁，一直是一整行 `发送给别人`（系统分享面板自带复制）。内容都传完时建好链接直接打开系统分享面板；还有没传完的先让人看到说明，由 TA 点发送。

## 分享设置（F-141，issue #96）

**入口：** 家人页设置里 `已分享的链接` 上面一行 `分享设置`，副标题 `有效期 7 天 · 显示名字` / `有效期 30 天 · 显示为“小宝”` / `… · 不显示名字`，选了头像时后面加 ` · 带头像`。条件和分享入口一样，另外服务端要认识这些选项（`/v1/config` 的 `shareDisplay`），旧服务端不显示这一行。

**设置弹层：** 三段，每段一个衬线小标题（`SectionTitle`）。`默认有效期` 胶囊 1 / 7 / 30 天（默认 7）；`分享时间线默认范围` 胶囊 `最近 7 天` / `最近 30 天`（默认）/ `全部`（“自定义”要选日期，不能当默认）；`对方看到的宝宝`：开关 `显示宝宝的名字`（开），开着时下面一个输入框 `称呼`（占位 `留空就用宝宝的名字`，最多 20 个字，超了或换行时红色小字说明、不能保存），关掉时开关下写 `页面上写“宝宝”`、输入框收起；开关 `显示宝宝的头像`（关），副标题 `放在页面顶上，发的是压缩过的小图`，没设置头像时写 `还没有设置头像，设置后才会显示`；一句灰色小字 `只换页面顶上的名字。回忆的标题和文字里写到的名字不会被换掉。`。最后一句说明这些是以后新建链接的默认值、跟着账号走、已经发出去的链接不变，下面是和 `创建链接` 一样的整行按钮 `保存`，保存后关闭并 Toast `已保存`。

**分享弹层里（一天、时间线、回忆三种都有）：** 在内容说明（开关或 `sand` 提示卡）下面、`有效期` 上面一行纸色圆角条：`对方看到：显示为“小宝” · 带头像`（13 号灰字，最多两行）+ 右边强调色 `修改`。点了就地展开成小标题 `对方看到的宝宝` 和上面同样的开关、输入框，只用于这一次，不改默认值。有效期胶囊和时间线范围从默认值开始。服务端不认识这些选项时整行不显示；这时如果默认值改过名字或头像，换成一张 `sand` 提示卡说这次的链接会显示真实名字、不带头像。称呼不合规时 `创建链接` 不能点。

**已分享的链接：** 名字或头像不是默认的链接，在 `到期日 到期 · 谁创建` 下面多一行同样的 `对方看到：…`。

**分享页（网页）：** 名字由服务端换好。不显示名字时标题照样写第几天，名字换成 `宝宝`（英文 `Baby`）：`宝宝的第 15 天`、`宝宝的成长时间线`、`宝宝的回忆`。带头像时标题区右上角一个 64 圆形头像（2 像素卡片色描边，外面一圈细线），日期和标题从左边绕过；alt 是 `宝宝的头像`，不写名字；打不开时整个去掉，不留破图。

**存在哪里：** 只存在这台手机上（`documentDirectory/theme.json`，读时过 zod），不同步：是看的人自己的喜好，全家可以用不同的主题。退出登录、换账号不清：不是宝宝的数据。启动时在第一次渲染前同步读出来，不会先闪一下默认配色。

**不跟主题的：** 桌面小工具（还是 SPEC“桌面小工具”的两套颜色，跟手机的深色模式）、分享出去的网页（别人看的）、导出的成长册 PDF（打印用，白纸黑字）。小工具跟主题要在后台任务里读这个文件、给五个小工具各画五套颜色，还要重新出预览图，这一版不做，主题页底下写明。

**主题配色页：** 家人页设置里 `主题配色` 一行（副标题 `暖纸 · 跟随手机`，所有角色都有），从右侧滑入，`‹ 家人` + 标题 + 一句说明（只改这台手机，马上生效）。先是 `浅色和深色` 分区：`跟随手机` / `浅色` / `深色` 三个胶囊，下面一句说明跟随手机时什么时候换。再是 `配色` 分区：每套主题一张卡片，上面并排两张小样（浅色、深色各一张：纸色底上一张卡片，墨色标题条、辅助文字条、三种记录的色点，下面一条点缀色按钮），下面衬线的名字和一句 `muted` 说明。正在用的那张边框换成 2 宽的点缀色，右边点缀色小字 `正在用`。最下面 `sand` 提示卡：桌面小工具和分享网页保持原来的颜色。点了马上换：界面重新挂载（和换语言一样），还停在这一页，页面回到顶部。深浅放在最上面就是因为这个：刚点的胶囊换完还在眼前。试过记住滚动位置、重新挂载后滚回去，会和接着的点击抢时机，放弃了。

**以后加颜色：** 只能加在 `palettes.ts`。页面里写颜色字面量、在模块顶层读 `colors.xxx`、在 Reanimated 的 worklet 里读 `colors` 都会被 `scripts/check-colors.mjs` 拦下来（接在 `pnpm test` 里）。模块顶层的样式表写成 `themedStyles(() => ({...}))`（代替 `StyleSheet.create`）。

## 桌面小工具（Android）

原型里没有，这一节是唯一依据。目的是半夜单手一下记好，所以：数字是主角，按钮够大，跟随手机的深色模式。

**通用：** 卡片圆角 20，内边距 13/14/12，没有边框。上排是色点 + 宝宝名字（12/700），右边按需放一句小字；中间一行 11 号小字说明这是什么，下面是 34 号 DM Mono 的钟点，再下面一行 12 号补充；底部是 38 高的胶囊按钮（14/700）。还没有记录时，钟点换成 16 号衬线标题加一句提示。钟点不是今天的，说明那行带上日期。按钮点了先把字换成 `记录中…`（颜色不变，后台任务一拉起就画，不等写完；再点还是同一条），写好后卡片变成“刚记好”：色点和说明变绿（`已记好 · 喂奶 120ml`），钟点是这条记录的时间，按钮变成绿色的 `修改或撤销`，点了打开这条记录。约 5 秒后恢复。

**同步时间：** 平时不显示。超过 30 分钟没同步或者从没同步过，右上角出现一个小胶囊 `18:10 同步`，提醒家人的记录可能还没到。

**不做实时计时：** 小工具最快 30 分钟刷新一次，所以一律写具体时刻（`约 23:40 该喂了`），不写“2 小时前”。

- **快捷记录（4×2）**：上排衬线 `小禾 · 第 33 天` 和日期；中间一行是最近的喂奶、睡眠、尿布（色点 + 等宽钟点 + 一两个字）；下面五个方形按钮：赤陶色的喂奶（上面小字 `喂奶`，下面等宽奶量，宽 1.35 倍）、三种尿布、蓝色的 `睡着了` / `醒了`。被点的按钮先写 `记录中…`，记好后中间那行变成绿色的 `已记好 · …，点绿色按钮修改或撤销`，被点的按钮变绿写 `已记好 / 修改`。
- **今日汇总（4×2）**：衬线 `小禾的今天` 和日期；一天的节奏条（0 点到 24 点，已过去的底色深一档，睡眠是蓝色段，喂奶的点在上、尿布的点在下，竖线是现在），下面一行 `0 6 12 18 24`；最下面三列：色点 + `喂奶 · 840ml` / `尿布` / `睡眠`，24 号等宽数字加单位。只写数量，不判断够不够。

**称呼和头像（每台手机自己设，不同步）：** 小工具上写的名字默认是宝宝档案里的名字，可以在 `桌面小工具` 页改成别的称呼（最多 12 个字，清空就回到名字），只影响这台手机上的小工具，App 里其他地方照旧写名字。头像默认不显示，打开 `在小工具上显示宝宝头像` 后：2×2 的三个小工具把上排的色点换成 16dp 的圆形头像，名字少放约一个汉字；快捷记录和今日汇总在衬线标题前放 22dp 的圆形头像，间距 7（快捷记录横向很宽，名字照旧放 12 格；今日汇总少放一个汉字）。色点被换掉后，“刚记好”和睡着时的状态仍由说明文字、钟点、按钮和夜蓝卡片表达。没有头像、头像还没准备好（家人刚换的，要等这台手机打开 App 才下载）时，和不开一样显示色点。深色模式下头像不加描边（模拟器上深色卡片配头像看过，边界清楚）。

**App 里的入口：** 家人页设置里的 `桌面小工具`，从右侧滑入，`‹ 家人` + 标题 + 一句说明，下面先是 `小工具上显示` 一组：输入框 `小工具上的称呼`（占位文字是宝宝的名字，边输入边保存，下面一行小字说明留空的含义和字数上限），开关 `在小工具上显示宝宝头像`（小字 `桌面上谁拿起这台手机都能看到，锁屏上不显示。`；打开了但宝宝没有头像时，下面多一行提示去今天页添加）。再往下是小工具列表：快捷记录和今日汇总是整行卡片，其余两列；每张卡片是 `sand` 底的预览图（和系统小部件列表里的同一张）、名称、一句说明、赤陶色 `添加到桌面`，点了请系统弹出添加窗口。桌面不支持时 Toast 提示。最下面是 `sand` 提示卡，写手动添加的路径（有的手机放在列表最下面的“安卓小部件”里）。

## 7. 相对原型的有意改动

| 原型                         | 现在                                                     | 原因                                       |
| ---------------------------- | -------------------------------------------------------- | ------------------------------------------ |
| Secret 看起来存在手机        | 只写入服务端，App 永远读不回来                           | 否则每台手机都能读全部证件                 |
| 自定义域名 + 10 分钟签名链接 | 私有文件走存储 API 域名，域名字段只用于公开读的 CDN 场景 | R2 预签名链接不支持自定义域名              |
| “新加坡节点 11ms”            | 显示真实的连接测试结果和耗时                             | R2 只能选 APAC，不保证在新加坡             |
| 乙肝第 2 剂在 1 个月         | 按 NCIS 改为随 2 个月六合一                              | 原型过时                                   |
| “6–8 次都正常；吃够了”       | 按真实数据给提示，偏少时建议留意                         | 不能在数据不足时安慰                       |
| 称呼“他”                     | “宝宝”或名字                                             | 不假定性别                                 |
| “证件本地加密”开关           | 改为证件夹指纹解锁                                       | 端到端加密的家庭密钥分发容易造成永久丢数据 |
| “流量下传压缩版”             | 视频等 Wi-Fi 再传                                        | 不改变原文件，更可靠                       |
| “瓶喂”                       | “喂奶”                                                   | 不是每次喂奶都用奶瓶                       |
| “本周可接种”                 | “可以预约了”                                             | 提前两周提示，这样说更准确                 |
| “私有访问”“缩略图”开关       | 不提供开关，两项始终开启                                 | 都是安全的默认值，不需要用户选择           |
| 记录不足时默认按 3 小时估算  | 至少 3 次喂奶后才估算下次时间                            | 默认的猜测不能用来驱动提醒                 |

## 8. 健康提示规则

规则和来源在 `packages/shared/src/health/`。体温：≥38℃ 红色“3 个月以下的宝宝 38℃ 及以上，请尽快就医”；37.5–38℃ 赤陶色“有点偏高，松松衣服，30 分钟后再量一次”；否则“正常范围”。判断永远用摄氏度，文字里的阈值按用户的单位显示（38℃ 写成 100.4°F）。
