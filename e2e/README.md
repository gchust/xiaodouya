## 流程的顺序

流程按文件名顺序跑，共用同一个 App 状态和 `RUN_ID`。`e2e.sh` 每次都会重装 App，所以只跑部分流程时也要带上它依赖的流程，比如 `pnpm e2e e2e/flows/01_onboarding.yaml e2e/flows/09_growth.yaml`。

| 流程 | 依赖               | 跑完留下的变化                   |
| ---- | ------------------ | -------------------------------- |
| 08   | 01                 | 多了吃药、洗澡记录               |
| 09   | 01，要在 12 之前   | 多了两条体重记录                 |
| 10   | 01                 | 卡介苗已接种                     |
| 10a  | 01，不依赖 10      | 无，隐藏、改时间、自己加的和补记的都还原了 |
| 11   | 01                 | 无，测试用的记录最后删掉了       |
| 11a  | 01、03、08、09、10，要在 12 之前 | 无，测试用的内容都删掉了，卡介苗的日期改回今天 |
| 12   | 01                 | 宝宝改名 Sprout2，出生档案填满了 |
| 13   | 01                 | 无                               |
| 14   | 03                 | 无                               |
| 14b  | 03、04             | 系统相册多了一张照片             |
| 15   | 05                 | 妈妈被移出家庭                   |
| 16   | 01、09、10         | 多了一条喂奶记录（118ml），地区换回新加坡 |
| 17   | 01                 | 多了自定义疫苗 Typhoid           |
| 18   | 10、17             | 多了自定义疫苗 Rabies，地区换回新加坡 |
| 19   | 03、04、10、11、12 | 退出后重新登录，仍然是管理员     |
| 20   | 03，要在 21 之前   | App 里登录的是只看回忆的外公     |
| 21   | 20，必须最后跑     | App 里登录的是一起记录的阿姨     |

新流程要用管理员身份的话，编号要排在 20 之前，并把 20、21 改名往后挪。
改地区的流程结束时要换回新加坡，也不要留下单位偏好：其他流程都按 `ml`、`℃`、`kg` 断言。

CI 和本地的服务端都用 `apps/server/.env.example`，里面开着自定义存储，所以管理员在流程 07 看到的是 S3 表单。用量页（线上托管模式时所有人看到的页面）由流程 21 用一起记录的家人覆盖。“托管模式下管理员看到用量页”这一条要换服务端配置，E2E 没有覆盖，只有单元测试。

## 用什么是真的，什么是模拟的

| 环节                           | 情况                                                     |
| ------------------------------ | -------------------------------------------------------- |
| 服务端、数据库、同步           | 真实                                                     |
| 预签名直传、S3 协议            | 真实（SeaweedFS，S3 兼容）                               |
| 上传后的校验                   | `verify-uploads.mjs` 直接查库并从 S3 读回对象            |
| 第二位家人、只看回忆的家人     | 脚本走真实接口                                           |
| 系统相册和相机                 | E2E 构建用内置样例代替，系统界面随版本变化，自动化不稳定 |
| 保存到系统相册                 | 真实，`e2e.sh` 收尾时查系统媒体库                        |
| 系统文件夹选择器               | E2E 构建换成 App 内的固定目录，之后的复制和重名处理是真的 |
| Cloudflare R2、AWS S3 本身     | 没有测，需要真实账号                                     |
| 后台上传、推送到达、厂商杀后台 | 模拟器测不了，发版前要在真机上验证                       |
